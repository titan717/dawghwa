## Shared rules (apply to every spec)

1. Tokens only. No literal colours, font sizes, radii or durations in new CSS. Five type sizes (`--text-2xl`, `--text-lg`, `--text-base`, `--text-sm`, `--text-2xs`). 4/8 spacing grid. One radius `--radius` (4px); `--radius-full` only for chips, toggles, avatars, dots.
2. Green (`--accent`) is action and state only. At most one green fill per view. Every green state also has a non-colour cue (check icon, text, position), because green on white is 1.53:1.
3. Targets: 44x44px hit area for every control (WCAG 2.5.8 floor is 24px; our product rule is 44px). Visual size may be smaller if the hit area is padded (inset `::before`).
4. Focus: `:focus-visible` outline 2px `--color-focus`, offset 2px. On a green fill add an outer 2px `--ink` ring (`box-shadow: 0 0 0 4px var(--ink)`) so the ring reads on light. Focused items are never fully covered by the top bar, bottom nav, sheets or toasts (2.4.11): set `scroll-padding` on `html` (DESIGN.md 13).
5. Motion: transform and opacity only. Every new duration/travel token is zeroed in both reduced-motion blocks in `tokens.css` (`@media (prefers-reduced-motion: reduce)` and `[data-reduce-motion]`).
6. Names: visible text starts the accessible name (2.5.3). Icon-only buttons have `aria-label` and a tooltip on fine pointer.
7. Copy: sentence case, plain, no source or provider words, generic errors, never HTTP codes.
8. Light/dark parity: every screen is checked in both. The bottom nav is black in both themes.
9. Screenshot scoring (MASTER_PROMPT section 12) uses these specs as the "Blueprint fidelity" reference.

| `--incognito-tint` | `#2a1f3d` | `#ede7f8` | Incognito top bar tint (plus icon + banner; never the only cue) |
| `--sepia-bg` / `--sepia-ink` | `#f4ecd8` / `#3b2f22` | same | Reader sepia background |
| `--sheet-travel` | 100% | 100% | Sheet enter translate |
| `--toast-travel` | 8px | 8px | Toast enter translate |
| `--page-travel` | 100% | 100% | Paged reader slide |
| `--tilt-max-x` / `--tilt-max-y` | 6deg / 8deg | same | Hero tilt, fine pointer only |
| `--swipe-fly` | 120% | 120% | Quiz card fly-out distance |
| `--toast-ms` / `--toast-action-ms` | 5000 / 8000 | same | Read by JS (`getComputedStyle`) |

Reduced-motion blocks set `--sheet-travel`, `--toast-travel`, `--page-travel`, `--swipe-fly` to `0`, `--tilt-max-x`/`--tilt-max-y` to `0deg`.
